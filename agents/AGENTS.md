# Agent Orchestration System

## Problem-Solving Protocol

**When encountering ANY problem:**

1. **Do research** - Understand the problem thoroughly before acting
2. **Root cause analysis** - NO jumping to conclusions or workarounds
3. **Fix the actual problem** - Not symptoms

**🚨 NO WORKAROUNDS**: Always find and fix the root cause. If you're tempted to
implement a workaround, stop and investigate deeper.

## Core Principles

1. **Root cause > workarounds** - Always fix the real problem
2. **Research before acting** - Understand before implementing
3. **Always run tests** - After any code change, run the project's test suite
   before reporting work as done. Compiling clean is not enough. If a test
   fails, investigate whether it's caused by your change (re-run with the same
   seed, run in isolation) before dismissing it as flaky.
4. **Finish the whole assigned task end-to-end.** When given a task (e.g. "full
   e2e now"), do ALL of it. Do not run a "focused subset", "representative
   pass", or "high-signal" slice and call it done — that is not the task. Keep
   going until the actual scope is complete.
5. **Never make judgements about time or effort.** Do not estimate or mention
   hours/days, "multi-hour", "multi-session", "many scenarios", or "this would
   take a while" to justify doing less. The size of the work is not a reason to
   scope it down — if it were too much, it wouldn't have been assigned. Just do
   the work.
6. **Don't stop partway to ask whether to continue.** No "want me to push on?",
   no checkpoints, no "is this sufficient?". Work straight through and report
   once, at completion. Only stop for a genuine blocker or a decision that is
   truly the user's to make.
